# 🏗️ AI Construction Chatbot (RAG-Based)

An AI-powered Construction Project Chatbot built using **Retrieval-Augmented Generation (RAG)**, **FAISS Vector Search**, **Groq LLM API**, and **Flask**.  

The chatbot intelligently retrieves relevant construction project data from large datasets and generates human-friendly responses using semantic search and Large Language Models (LLMs).

---

# 🚀 Features

- 🔍 Semantic Search using FAISS
- 🤖 AI-Powered Responses using Groq LLM
- 🧠 Retrieval-Augmented Generation (RAG)
- 🏢 Construction Project Analysis
- 💬 Natural Language Query Support
- 📊 Building Area & Cost Analysis
- ⚡ Fast Vector Retrieval
- 🌐 Interactive Chatbot UI
- 📁 Large Dataset Support
- 🧾 Human-Friendly Response Formatting
